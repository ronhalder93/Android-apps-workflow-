# RGB Glow Keyboard (Android)

A small native Android Input Method Service starter project with animated RGB glow styling and a QWERTY layout.

## Build
Open this repository in Android Studio, allow Gradle sync, then build the debug APK.

## Enable
Install the APK, open RGB Glow Keyboard, tap **Enable keyboard**, enable it in Android settings, then choose it from the input-method picker.

## Notes
This is an initial source project, not a compiled APK. The keyboard draws its own UI; it is not Google Gboard and does not include Gboard's proprietary features. Review and test before daily use.
